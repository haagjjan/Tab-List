# Legal Resources

`Sparkle-LICENSE.txt` is an unmodified copy of the license at the Sparkle 2.9.4
tag, resolved to commit `b6496a74a087257ef5e6da1c5b29a447a60f5bd7`.

When Sparkle is upgraded:

1. Replace this file with the license from the exact resolved revision.
2. Update `project.yml` and the Xcode workspace `Package.resolved`.
3. Review `THIRD_PARTY_NOTICES.md`.
4. Run the complete release verification before publication.

Tab-List’s own `LICENSE`, `PRIVACY.md`, and `THIRD_PARTY_NOTICES.md` remain at
the repository root. Xcode packages those source-of-truth files directly rather
than maintaining duplicate copies here.
