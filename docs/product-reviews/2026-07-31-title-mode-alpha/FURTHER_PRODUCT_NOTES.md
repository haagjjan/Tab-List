# Tab‑List Title Mode — Internal Alpha Product Review 

## Summary:
This consits of TLAR's that are of not high necessity to be implemented soon. 
Including additional features, polishment of non core features, fixing of minor visual bugs or
naming conventions of buttons and descriptions.

### TLAR-001 - The list functionlality Name 

**Observed**
The current List funtionality, is named "Title" however this is actually a list, not a title.

**Requiered Adjustment**
The Button besides: *Thumbnails* *App Icons* needs to be renamed to *List*.

**Acceptance Criteria**
The currently named *Title* button is named *List*.


### TLAR-002 - Color adjustments

**Observed**
When having the TabList in use, the element that gets switched to on releas
is circeled by a blue line.

**Requiered Adjustment**
This circeled blue line should be freely replacable with a other color of 
the users choice.

**Acceptance Criteria**
The user can freely choose a other option as a color that shows the currently
selected document.

### TLAR-003 - One application corner case

**Observed**
When only having a singular window open that meets the criteria to be shown,
the element does not show up, and by clicking *CMD+Tab* the menue does not
get opened

**Requiered Adjustment**
The *CMD+Tab* menue / functionality should be opened whenever there is 1
or more then one Windows that meet the criteria to be swichable.

**Acceptance Criteria**
The *CMD+Tab* menue must always be opened, as long as there is at least one
viable element to be opened.
